# FINOVA Beta App — Vercel Deployment

This is a static HTML app. No build framework or backend is required.

## Deploy with GitHub + Vercel

1. Create a new GitHub repository (for example: `finova-beta-app`).
2. Upload `index.html` to the repository root.
3. Open Vercel and sign in with GitHub.
4. Select **Add New → Project**.
5. Import the `finova-beta-app` repository.
6. In project settings, use:
   - Framework Preset: **Other**
   - Build Command: leave blank
   - Output Directory: leave blank (or `.` if Vercel requires a value)
   - Install Command: leave blank
7. Click **Deploy**.
8. Open the generated `*.vercel.app` URL on a phone to test.
9. Create a QR code from that public URL for the class.

Note: This is a classroom simulation only. It does not connect to a bank, process real payments, or store real customer data. Do not enter real personal or banking information.
