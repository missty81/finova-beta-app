# FINOVA Beta 2.0 — Classroom Simulation

Static HTML fintech interface for Project Quality Management classroom testing.

## Deploy to Vercel
1. Upload `index.html` to the root of a GitHub repository.
2. Import the repository into Vercel.
3. Select Framework Preset: Other.
4. Leave Build Command empty.
5. Set Output Directory to `.` if required.
6. Deploy.

Fictional classroom simulation only. No banking/payment systems are connected. Do not enter real personal or financial information.
